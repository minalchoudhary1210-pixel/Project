# Healthcare Analytics – Business Analysis Project

A Data-Driven Approach to Predicting Diabetes Using Machine Learning

## Project Overview

This project focuses on predicting the likelihood of diabetes in patients using machine learning techniques.
Using the *Pima Indians Diabetes dataset*, the project includes complete end-to-end steps from data preprocessing to model evaluation, visualization, and insights.

This repository is ideal for:

* Business Analytics students
* Machine Learning beginners
* Portfolio/Resume showcasing
* Healthcare analytics research

## Objectives

* Analyze health parameters such as glucose, BMI, insulin, pregnancy count, and age
* Apply machine learning algorithms to classify diabetes outcomes
* Understand data distributions, correlations, and model performance
* Build a prediction system showcasing practical business analytics skills

---

## Data Preprocessing

The project includes:

* Handling missing values
* Feature scaling
* Exploratory Data Analysis (EDA)
* Correlation heatmaps
* Feature engineering

## Machine Learning Models Used

The notebook compares multiple ML models including:

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

Performance metrics used:

* Accuracy
* Precision
* Recall
* Confusion Matrix

## Visualizations

The project includes visual analytics such as:

* Histograms and KDEs for key features
* Correlation matrix
* Model comparison charts
* Feature importance plots

---

## Key Insights

✔ Glucose, BMI, and age have the strongest correlation with diabetes outcome
✔ Ensemble models (like Random Forest) show better prediction accuracy
✔ Imbalanced target distribution impacts model performance
✔ Proper preprocessing significantly improves prediction quality
